# Dashboard analise de vendas e-commerce
Analisar  o desempenho de vendas de uma loja virtual, identificando categorias de produtos com maior saída e o comportamento do ticket médio para auxiliar na tomada de decisão comercial.

## Ferramentas Utilizadas
* Power BI Desktop: Construção de Dashboard e tratamento de dados.
* DAX: Criação de medidas Calculadas(Faturamento, Qtd Vendida, Ticket Médio).
* Excel/CSV: Base de dados tratada.

## Principais indicadores
* Faturamento Total: Valor acumulado em vendas.
* Ticket Médio: Média de valor por pedida.
* Sazonalidade: Análise temporal das vendas.

## Insight Principal
Através da segmentação de dados, foi possível identificar que a categoria Eletrônicos possui maior volume de faturamento, representando a maior parte da receita total do período analidado.
